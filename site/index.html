Method

The sample

Up to 1,000 pages from each Common Crawl snapshot collected by this project, chosen by a salted hash of the URL so the same pages are chosen every time. A URL that appears in several crawls counts once, in its earliest crawl. The crawl collector kept English pages only.

The visit

Each page gets one polite GET request: an identifying user agent, at most two requests in flight per site, a 15 second timeout, and the first 512 KB of the body. Redirects are followed. The same sample is revisited each month, so the curve becomes a record of decay over time.

Judging the fate

The visible text of the live page is compared to the text Common Crawl captured, using 64-bit SimHash fingerprints of three-word shingles. Distance 0 means the same wording; around 32 means unrelated text. The thresholds are heuristics and are published here so you can judge them.

Limits

  • This is a sample of what Common Crawl captured, and of the files this project pulled from each crawl. It is not a random sample of the whole web.
  • Every visit comes from one cloud network. Sites that block data-center traffic, demand JavaScript, or geo-restrict show up as unknown, not dead, and are left out of the shares.
  • Soft-404 and parking detection use patterns in the page text and will miss some cases in both directions.
  • "Drifted" pages answer at the same address with different text. Some are real replacements; some are the same article in a new site design. The fingerprint cannot always tell them apart.
  • Archive coverage is estimated from a random subset of dead and drifted pages checked against the Wayback Machine's availability API.
